Scaffold, not a gate

A scaffold, not a gate.

Any ecosystem can author and operate an Ecosystem Governance Framework on Verana. No Council approval is required. The Template EGF is a working scaffold (pre-filled with the Network GF interface, standard permission structures, and placeholder sections) that the Council maintains to make authoring a sector EGF cheaper and more interoperable.

What the Template EGF provides

  • Network GF interface section. Pre-filled with the non-negotiables from the Network GF so your EGF satisfies its requirements by construction.
  • Permission structure boilerplate. Standard patterns for issuer onboarding, verifier onboarding, holder onboarding, and accreditation workflows.
  • Risk-management alignment. A scaffold that wires your EGF's risk process into the graduated sanctions rubric specified in the Network GF.
  • Glossary and terminology. Consistent usage of Verifiable Trust terminology so your EGF reads in the same voice as the Network GF and ECS-EGF.
  • Publication checklist. Concrete list of artifacts your EGF MUST publish (controller DID, version, SRI hash, amendment process) to be resolvable on Verana.

What the Template EGF is not

  • Not an approval step. Using the Template is optional. Ecosystems may author their own EGF from scratch.
  • Not mandatory content. Nothing in the Template is normative; only the Network GF is.
  • Not a Council endorsement. The Council does not endorse any sector EGF.
