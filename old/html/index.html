The governance body of the open public trust layer.

The Verana Council Association authors and operates the two frameworks that govern verifiable trust on the Verana network, and it secures the chain on which they run. Non-profit Swiss Verein. One-member-one-vote. Founding Members co-author the rules through Q3 2026.

What the Council governs

Two frameworks. One chain to secure. One seat-diversity rule to enforce.

The Verana Council's remit is bounded. It authors and operates exactly two governance frameworks, secures the chain those frameworks run on, and enforces a one-voice-per-sector-per-region seat-diversity rule on its own composition.

1. Constitutional layer

Verana Network Governance Framework

Defines the rules every Ecosystem Governance Framework on Verana must respect: permission lifecycle, Trust Deposit mechanics, graduated risk-management rubric, dispute-resolution process, chain-evolution process. Any ecosystem may create an EGF on Verana. The Network GF is not an approval gate; it is the set of requirements every EGF must satisfy.

Read the Network GF →

2. Ecosystem layer

ECS Ecosystem Governance Framework

Covers the four fixed Essential Credential Schemas (Service, Organization, Persona, UserAgent), defines the permission-management mode for each, and sets the rules under which the Council selects Issuer Grantors and Issuers per (schema × jurisdiction).

Read the ECS-EGF →

Plus a scaffold, not a gate: the Template EGF. Published by the Council as working scaffolding for ecosystems building their own sector EGF. The Council neither reviews nor approves sector EGFs. Anyone can create one. Download the Template EGF →

Foundational primitives

Open standards

W3C · DIF · Hyperledger · OpenWallet Foundation · OpenID Foundation · Trust over IP
Not built by the Council; composed under Verana specs.

Standards bodies define the foundational primitives: DIDs, Verifiable Credentials, Presentation Exchange, did:webvh, Linked-VP, AnonCreds, credo-ts, OpenID4VCI / OpenID4VP, the ToIP layered governance model. The Verana network composes those primitives into a public trust registry specified in CC-BY-SA 4.0. The Verana Council governs the network: authoring the frameworks, selecting ECS accreditations, operating the validator set, and enforcing the Code of Conduct.

The Council does not build standards, does not build products, and does not approve sector ecosystems. Its remit is the governance layer itself.

Founding Members write the rules

The Association incorporates Q3 2026. Join before the rules are written.

Today we are signing non-binding Letters of Intent with an exceptional cohort of governments, enterprises, standards bodies, and academic institutions. When the Association incorporates, LOI signers become Founding Members and co-author:

  • the Association's bylaws and seat-diversity rules,
  • the Verana Network Governance Framework (the rules every EGF must respect, the risk-management rubric, the dispute-resolution process),
  • the ECS Ecosystem Governance Framework (the ECS issuer accreditation policy and risk-management rubric),
  • the Template EGF (the scaffold the Council publishes for ecosystems building their own).

Later members inherit what the Founding Members decide.
